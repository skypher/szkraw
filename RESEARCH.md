## Szwarc's quadratic system (Section 7)

Problem 2 of Szwarc's survey (printed pp. 125–126) also introduces the symmetric recurrence yQ_{2n} = (N−n)Q_{2n+1} + nQ_{2n−1}, yQ_{2n−1} = (1−p_0)Q_{2n} + p_0Q_{2n−2} with Q_{2n}(y) = K_n(y²), and asks for a general criterion that would handle it. Sections 2–6 did not address this system. Section 7 adds:

- Theorem 7.1: nonnegative linearization of the stochastic form of Q for all N ≥ 1 and 0 < p_0 ≤ 1/2, with g(2,2;2) < 0 for p_0 > 1/2. Proof: a graded module V = A ⊕ ⊕_l f_lA over the q = 1 algebra, with edge idempotents f_l = (r + y_l)/(1+r) satisfying y_l f_l = f_l, and an A-linear operator Y realizing the recurrence. The even part recovers Corollary 6.1 through Szwarc's quadratic route.
- Lemma 7.4: margin (rs/8)^N on the symmetric triangle support for 0 < p_0 < 1/2.
- Lemma 7.5: Theorem 5.3's estimate stated for any reference with nonnegative linearization, a lower bound α on upward coefficients, and a margin δ.
- Theorem 7.6: every symmetric stochastic array within η = ½(rs/8)^N(16N)^{−2N} of Szwarc's array (0 < p_0 < 1/2) has nonnegative linearization. Corollary 7.7 gives arrays outside both the Szwarc and geometric families.

- Theorem 7.8 (quadratic decomposition): every symmetric finite array (length 2N+1) has nonnegative linearization whenever its even and odd components — explicit arrays of lengths N+1 and N built from products of its coefficients — do; g(2a,2b;2c) = ĝ(a,b;c) and g(2a,2b+1;2c+1) = a_{2a}ǧ(a,b;c) + c_{2a}ǧ(a−1,b;c). Any criterion for nonsymmetric finite systems (Theorems 2.1, 5.3, Lemma 7.5) therefore transfers to symmetric ones.
- Corollary 7.9 (parity-split criterion): constant odd downward coefficients p_0 ≤ 1/2 and even downward coefficients with geometric increments (ratio q ≥ 1) give nonnegative linearization; the components are geometric(N,q,r) and geometric(N−1,q,r/q). q = 1 is Szwarc's system; q > 1 is a new three-parameter symmetric family. Sharp at p_0 > 1/2.

Exact diagnostics: szwarc_check.py, called from verify.py, checks Theorem 7.1 and Lemma 7.4 on 42 arrays (N ≤ 7), sharpness for p_0 ∈ {3/5, 9/10}, the identities of Lemmas 7.2–7.3 and the product mechanism U_mU_n = Σ g U_k in the graded model (N ≤ 4, including r > 1), and the margin of Theorem 7.6 on 18 rational symmetric perturbations (N ≤ 3). run_decomposition checks Corollary 7.9 on 45 arrays (N ≤ 6, q ∈ {1,3/2,2}) including exact identification of both components, and the formulas of Theorem 7.8 entrywise on random symmetric arrays. These are diagnostics, not the proof.

Status: Section 7 has no Lean formalization and no independent review. An earlier exploratory approach through Szwarc's discrete hyperbolic certificates (checkerboard cones on the finite grid) was abandoned; in particular, the vanishing g(m,n;k) = 0 for m+n+k > 2M holds for symmetric Krawtchouk but is false in general and is not used anywhere.

## Inequality-type criteria: negative result

The natural conjecture "constant ratio b/c with r ≤ 1/2 and convex profile d implies nonnegative linearization" survives random sampling and adversarial optimization up to N = 10, but is false: one-kink convex profiles give exact counterexamples g(14,14;14) < 0 at r = 1/2 (N = 14) and g(20,20;20) < 0 at r = 2/5 (N = 20), replayed in verify.py. Float scans suggest the admissible r for convex profiles decreases with N. ## Deep triples: lightcone certificates and other approaches (negative results)

deep_certificates.py (not called from verify.py; the linear programs need numpy and scipy and run in floating point, the other checks are exact) tests four proposed routes to an inequality criterion for the deep triples of Theorem 7.13. Fix k, put u(x,y) = g(x,y;k), and call v a certificate for the deep point (n,m) if <Hu,v> = 0 expresses u(n,m) as a combination of other values with coefficients (H*v)(p) that are nonnegative wherever u(p) is already known to be nonnegative and zero elsewhere. Counts below are deep triples (n,m,k) with n >= m.

- Tilted reversal (insert T between the two factors of Theorem 7.13): vacuous. The top-row factor W[t][z] = g(N,N−t;z) is triangular with positive diagonal, so T = W always works and merely reproduces the deep coefficients; the existence of T is equivalent to (P). The explicit choice T = W at r = 1 keeps T⁻¹W ≥ 0 but gives negative entries in the other factor (min −1/2 at N = 4, r = 1/2; −8 at N = 6, r = 1/5).
- Site-dependent tower generators y_j ∈ {1, −r_j}: Y = Σ y_j has N+1 distinct values only when all r_j are equal (8 values for r = (1/2,1/2,1/2,2/5), 15 for generic r_j at N = 4), so the generated system is no longer an (N+1)-point system.
- Curvature compensated by the diagonal: on the N = 14 counterexample profile (P) holds for r ≤ 2/5 and at r = 1 but fails at r = 1/2 and 7/10. More diagonal does repair the curvature, but the admissible set is not convex in the coefficients, and a threshold "deviation ≤ ε(N,r)" reduces to the perturbation criterion; no precise criterion was formulated.
- Lightcone weights on the backward cone {j < m, |i−n| < m−j}:
  - Free weights certify every deep point of Krawtchouk at N = 5 and 8 for r = 1, 1/2, 1/5 (90/90 at N = 8), even when only non-deep values (given by Theorem 7.10) are used ("one-shot"). The search is sound: it refuses the negative coefficient g(14,14;14) of the N = 14 counterexample. So the product-weight obstruction recorded in MISSION.md does not extend to general weights.
  - The weights must depend on the coefficients. No single v serves r = 1/5 and r = 1/2 (41/90 at N = 8, 14/27 at N = 5; failures already at N = 4). The same holds after renormalizing by σ_n = r^{n/2} or in Szwarc's normalization (3.9). Since H*v is linear in the coefficients for fixed v, no criterion consisting of linear inequalities in the coefficients obtained this way contains the Krawtchouk segment.
  - Szwarc's checkerboard support, with free weights, certifies 90/90 at r = 1 but 24/90 for every tested r < 1, including r = 99/100. Nonnegative weights certify 24/90 at r = 1 and 51/90 at r = 1/2. One-coordinate weights (functions of i+j, i−j, i or j) certify at most 21/90.
  - The canonical Riemann function (H*v = 0 at every deep point except the apex, obtained by marching; exact arithmetic) satisfies the identity u(n,m) = Σ flux·u exactly, but its flux onto the non-deep boundary is negative at most deep points, already for symmetric Krawtchouk (flux −7 at (8,8,1), r = 1; nonnegative at 4/90).
  - By Farkas, one-shot certificates at all deep points are equivalent to a maximum principle for H (solutions nonnegative off the deep corner are nonnegative on it). On 60 random perturbed Krawtchouk arrays (N = 6) it held exactly when (P) held (32 both, 28 neither, 0 disagreements), so it is a restatement of (P), not a weaker target.

Two further exact probes (deep_order.py, needs only probe.py):

- Order of vanishing at the symmetric endpoint. For Krawtchouk with N = 5, 6, 8, every deep coefficient g(m,n;k) vanishes as r → 1 to order exactly max(m+n+k−2N, (m+n+k) mod 2) in 1−r, that is, in the diagonal b = (1−r)d (159/159 deep triples; order read off exact values at 1−r = 10⁻³ and 10⁻⁴). On the hypercube model at r = 1 the zeros are the perimeter bound d(0,x)+d(x,y)+d(y,0) ≤ 2N; for r < 1 each unit of excess costs one diagonal factor. A certificate for the deep triples must therefore reproduce a zero of order m+n+k−2N in the diagonal, which certificates with weights linear in the coefficients do not do (consistent with the coefficient-dependence found above). It points to expansions in which every deep configuration carries at least m+n+k−2N diagonal (level-step) weights: path models of Viennot type, or the Boolean model of Lemma 5.2.
- No comparison in the top diagonal. Raising b_N (with c_N lowered) changes deep coefficients in both directions (e.g. N = 8, r = 1/5: 21 up, 61 down, 8 unchanged); raising b_{N−1} likewise. So "more diagonal at the top" does not monotonically help, and a comparison principle in the terminal coefficients is not available.

Conclusion: every lightcone variant tested either fails or is as hard as (P). A criterion covering asymmetric Krawtchouk and Q_n with p_0 < 1/2 must use the increasing diagonal actively rather than absorb it into positive margins.

## Deep triples: path models and the mirror pairing (2026-10-21)

path_model.py (exact except the linear programs, which need numpy and scipy) tests signed path counting with sign-reversing pairings as a route to an inequality criterion. Results for Krawtchouk unless stated:

- Viennot expansion (monomer–dimer tilings × lattice paths, level weight b_h − b_i). Low products already cancel heavily (positive mass up to 2.1·10³ times the net value at N = 6), although Szwarc's theorem proves them; the expansion gives no location for the deep obstruction. Zeng's colored-derangement model (SIAM J. Math. Anal. 21, 1990) likewise does not show Krawtchouk positivity without symmetric functions.
- Szwarc lightcone expansion (normalization (3.9), σ_n = r^(n/2), r = s² rational). For every deep apex the only negative weights are γ_x − α_y = s(1 − d_x − d_y) on the cone edge x − y = n − m at points with x + y ≥ N − 1, i.e. hypothesis (iii) of Theorem 7.10 failing past the antidiagonal. Truncation at the ceiling creates no negative weight.
- Mirror pairing M(x,y) = (N−y, N−x). If λ_i = a_{i−1}c_i is palindromic (all Krawtchouk arrays; not the geometric q > 1 arrays), a normalization with A_{N−i} = C_i exists and each defect pairs with a side-edge weight of exactly opposite sign. At r = 1 the values also agree and the cancellation is exact. In general w = u − u∘M satisfies Hw = −(e_x − e_y)·u∘M with e_i = b_i − b_{N−i}, vanishes on x + y = N, and the source has a fixed sign when e is nondecreasing; so the rising diagonal enters as a signed source.
- Mirror dominance (w ≥ 0 for x + y > N) holds exactly for Krawtchouk at N = 4, 6, 8, 10 and r ∈ {1/25, 1/4, 81/100, 9801/10000}. With Theorem 7.10 it implies (P). But on 293 random palindromic-λ arrays with e nondecreasing and nonnegative low products it held exactly when (P) held (238 both, 55 neither), so it is a restatement of (P) in that class, not a weaker target; and that class is not a criterion. None of b nondecreasing, c nondecreasing, λ concave, λ log-concave separates the 55 failures (34–53 failures remain under each).
- Maximum-principle certificates for w (coefficient-only sign conditions, induction over high points) exist at every high apex for t = 1/s − s = 4 (r ≈ 0.056), N = 4, 6, 8, but fail near (N,N) for t = 1/2 (r ≈ 0.61), and no single certificate serves both values. The mirror pairing therefore shrinks the obstruction to a corner near (N,N) without removing it.

Conclusion: signed path counting yields one genuine structure (the mirror involution, which removes the side-edge defects exactly for palindromic λ) but no criterion; the remaining corner problem is again equivalent to (P) on tested arrays.

## Deep triples: polynomial certificates near the symmetric endpoint (2026-10-21)

endpoint_probe.py (exact; the first-order formulas use sympy) tests polynomial certificates in the coefficients. In Szwarc's normalization (3.9) with σ_n = r^(n/2), divided by √r, the Krawtchouk array is x P_n = d_{n+1}P_{n+1} + t d_nP_n + (1−d_{n−1})P_{n−1} with t = 1/√r − √r: only the diagonal depends on r. Families studied: (c_{n+1}, B_n, 1−c_{n−1}) with c palindromic and increasing; B = 0 is Corollary 7.15's class and B = t·c contains every Krawtchouk array.

- Krawtchouk: every product coefficient is a polynomial in t with nonnegative coefficients and lowest power exactly max(m+n+k−2N, parity) (N = 4, 6, 8, 10). This is the Boolean model of Lemma 5.2 rewritten (the t^s term collects the configurations with s retained overlap coordinates), not a new mechanism.
- Palindromic B = 0: g(x,y;z) = g(N−x,N−y;z) exactly (from R_N R_{N−t} = R_t), so g = 0 whenever x+y+z > 2N, for every profile c. Krawtchouk is special only in the order to which deep coefficients vanish as t → 0 (the excess); for other profiles it is 1 (or the parity), and the sign of the first t-derivative depends on c.
- Free diagonal on the Krawtchouk off-diagonal part: first-order terms at deep entries are palindromic forms with zero sum, including fourth differences of the increments (g(5,5;5) ≈ (δ₁−4δ₂+6δ₃−4δ₄+δ₅)/6). A nondecreasing diagonal does not suffice: N = 3, B = (0, 1/10, 1/10, 1/10) gives g(3,3;3) = −1/20.
- Diagonal locked to the profile, B = t·c: d/dt g(3,N;N) at t = 0 equals (3c₁−1)/c₁ (N = 3), (4c₁−1)/c₁ (N = 4), (1−c₁)(2c₁−c₂)/(c₁c₂(1−c₂)) (N = 5), i.e. first increment ≥ second, with equality at Krawtchouk. The tangent cone at Krawtchouk in half-increment drops d_s = δ_s − δ_{s+1} is 0 ≤ d₁ ≤ κ_N d₂ with κ_N = 3, 2, 5/3 for N = 5, 6, 7, plus conditions on later drops at N = 7.
- Shape conditions tested for "(P) for all t ≥ 0" (exact root counting on (0,∞)):
  - U-shaped increments (shrinking toward the middle): all 90 random arrays pass for N ≤ 5; fails from N = 6 (increments (97,87,85,85,87,97): g(5,6;6) < 0 at t = 1/10).
  - Concave, decreasing half-increments: 138 of 140 random arrays pass up to N = 14, and the strong form (nonnegative t-coefficients) already fails at N = 11 without loss of (P). Exact counterexamples at N = 13 (middle increment 1/487) and N = 14: half-increments (88,88,87,86,85,77,50) at t = 11/200 (r ≈ 0.95) give g(7,14;14) ≈ −3.1·10⁻³.
  - Concavity is not necessary either: drops (2,1,…,1) pass up to N = 12.

- First-order tangent cone at Krawtchouk (endpoint_probe.py item 5; drops d_n = −Δ²c_n at nodes n < N/2). It does not collapse as N grows: the smooth U-shaped directions |x−½|, (x−½)², |x−½|^{1/2} (x = n/N) stay inside for every N ≤ 20, while −|x−½|, −(x−½)², (x−½)⁴ and ±cos 4πx are outside. Every N ≤ 20 obeys the following pattern exactly. The range of d_n/d_{n+1} over the cone is [0, (N/2−n)/(N/2−n−1)] (2, 3/2, 4/3, … counted from the middle), which is the projection of "d ≥ 0 and d_n/(N/2−n) nondecreasing". The cone itself is smaller: of the rays d_n = (N/2−n)·1[n > j] only j = 0 (a cubic perturbation of the Krawtchouk profile) and the last one lie inside; the flat-start rays are outside for N ≥ 9 (odd) and N ≥ 10 (even). Its extreme rays depend on N.
- Global ratio hypothesis (d_n ≥ 0 and d_n/(N/2−n) nondecreasing, with B = t·c) fails: N = 11, increments (19,19,19,19,6,1,6,19,19,19,19)/169 at t = 3/25 (r ≈ 0.89) give g(11,11;11) ≈ −9.3·10⁻³ (exact, item 6).
- Scope: all families in this section carry two exact equations (palindromic off-diagonal part, diagonal proportional to c) and exclude the geometric q > 1 arrays, so even a surviving shape condition would have given a mixed equality/inequality rule, not the inequality-only criterion that remains open. The shape search is closed.

Conclusion: polynomial certificates explain the Krawtchouk range and locate the difficulty at the symmetric endpoint: as r → 1 the deep coefficients leave the forced zeros with first-order slopes given by N-dependent forms in the profile, and every shape cone tested (monotone, convex, log-convex, U-shaped, concave) fails these for large enough N, consistent with the convex counterexamples above. This also settles the expansion test proposed as "tool 3": the leading terms are not positive combinations of products of increments.

## Toward a disproof: first-order structure at the symmetric endpoint (2026-10-21)

Goal set by the user: if no inequality criterion exists, prove that. A disproof can only exclude a precisely defined class. In the broad sense, inequality-defined criteria covering the full Krawtchouk range already exist: an equality is two inequalities, and the neighbourhoods of Theorem 5.3 are inequalities. rigidity_probe.py tests two candidate classes at K(N,1), in stochastic coordinates b_1..b_{N−1}, c_1..c_N (b_0 = 0 without loss of generality). Any convex set of arrays with (P) containing K(N,1) lies in K(N,1) + T_N, where T_N = {v : ∇g_p·v ≥ 0 at every structural zero p} (the parity and perimeter zeros in the triangle).

- Fixed N: no rigidity. T_N has no implicit equalities for N = 3–10, so it is full-dimensional. For an interior direction v, every first-order slack is strictly positive (exact), and K(N,1) + εv has (P) exactly for ε = 10⁻³ and 10⁻⁵ (N = 4, 6, 8, 10). So sets with (P) and nonempty interior touch the symmetric endpoint, and the disproof "every criterion through K(N,1) is forced into equalities" is false. The interior shrinks with N (LP margin 0.36, 0.21, 0.12, 0.067, 0.037, 0.020, 0.011 for N = 4, 6, …, 16).
- N-uniform rules: δb_n = β(n/N), δc_n = γ(n/N), with the same β, γ for every N. For polynomials of degree d, an interior rule exists for all 3 ≤ N ≤ d+2 and for no range 3 ≤ N ≤ d+3 (d = 3, 5, …, 13; degree 1 fails already for N = 3, 4). For constant rules, an exact certificate settles it: the slacks at g(3,3;3) (N = 3) and g(4,6;6), g(6,6;6) (N = 7) have the positive combination (247/960, 41/64, 1) vanishing identically, forcing β₀ = γ₀ = 0.
- Open: whether a non-polynomial smooth rule is interior for every N. Finite-dimensional tests cannot decide it. It needs the large-N limit of the constraints, which is the remaining step toward a disproof for N-uniform criteria.

## First-order obstruction for uniform deformations at the symmetric endpoint (2026-10-21; scope corrected after review)

Scope (corrected after the independent review, see REVIEW.md). A *uniform rule* is a pair of real functions (β, γ) on [0,1] acting on every size at once by δb_n = β(n/N) (1 ≤ n ≤ N−1) and δc_n = γ(n/N) (1 ≤ n ≤ N), in the stochastic coordinates above (a_n absorbs the change, b_N = 1 − c_N). A set of arrays *admits* the rule at the symmetric endpoint if there is N₀ such that for every N ≥ N₀ there is ε_N > 0 with K(N,1) + εv_N in the set for 0 < ε < ε_N. Result: a set with (P) admits only polynomial or analytic rules satisfying two exact boundary equalities, so no such set admits an open set of polynomial rules of bounded degree. This does not exclude arbitrary uniform inequality criteria, nor admissible families of other forms. The paper's equality-type criteria (Theorem 2.1, Corollary 7.15) satisfy the equalities.

**Lemma (corner identity).** At K(N,1), the first-order change of g(N,N;N) in direction v is

  ġ = s_N Σ_{n=0}^{N} (−1)^n C(N,n) F_N(n),  s_N = (−1)^{⌊N/2⌋+1} / C(N−1, ⌊(N−1)/2⌋),

with F_N = δb + 2δc for even N, F_N = δb for odd N, and conventions δb_0 = δc_0 = 0, δb_N = −δc_N.

*Proof.* At K(N,1), R_N(λ_j) = (−1)^j, so R_N(J) = Π (index reversal). Let X = d/dε R_N(J + εE). Commutation and the fixed first row (R_N R_0 = R_N) give [J, X] = [Π, E] and e_0ᵀX = 0. Use the eigenbasis u_j = (R_n(λ_j))_n, v_j = (w_j h_n R_n(λ_j))_n, with λ_j = 1 − 2j/N, w_j = C(N,j)/2^N, h_n = C(N,n). Then X_ij = ((−1)^i − (−1)^j)E_ij/(λ_i − λ_j) for i ≠ j, and Σ_i X_ij = 0. Hence ġ = X_NN = 2N Σ_{i+j odd} (−1)^i E_ij w_j/(i − j). For a perturbation of row n, E = e_n rᵀ and E_ij = w_i h_n R_n(λ_i)(r·u_j). Write ((−1)^i − (−1)^j)/(i − j) = −π∫₀¹ sin π(θi + (1−θ)j) dθ, and use Σ_i C(N,i)R_n(λ_i)s^i = (1+s)^{N−n}(1−s)^n. The double sum becomes Im of a product of two generating functions at s = e^{iπθ} and s = −e^{−iπθ}, and evaluates to (−1)^n times a beta integral independent of n:
- r = e_n − e_{n+1} (coordinate b_n): ġ = 2N C(N,n)(−1)^n (−1)^{⌊N/2⌋+1} I_N, with I_N = ∫₀^{π/2} cos^{N+1}φ sin^{N−1}φ dφ (N even) or ∫ cos^N φ sin^N φ dφ (N odd);
- r = e_{n−1} − e_{n+1} (coordinate c_n, n < N): twice that for N even (the ratio of the two beta integrals is 2), zero for N odd;
- coordinate c_N (r = e_{N−1} − e_N): ġ = 2N(−1)^{⌊N/2⌋+1}I_N.

Finally 2N·I_N = 1/C(N−1, ⌊(N−1)/2⌋). ∎ (rigidity_probe.py item 4 checks the identity exactly for N = 2–20.)

**Theorem.** Let β, γ be polynomials, and put L_even = β(0) + 2γ(0) + β(1) + γ(1) and L_odd = β(0) − β(1) − γ(1). For N > deg, Σ_{n=0}^{N}(−1)^n C(N,n)p(n/N) = 0 for every polynomial p of degree < N. So only boundary values survive in the Lemma: ġ = −s_N L_even (N even) and ġ = −s_N L_odd (N odd). Since s_N changes sign from N to N+2, L_even ≠ 0 (resp. L_odd ≠ 0) gives ġ < 0 for every large N in one residue class mod 4 among the even (resp. odd) N. Then g(N,N;N) < 0 at K(N,1) + εv_N for small ε > 0, so (P) fails. If L_even = L_odd = 0, then ġ = 0 for N > deg, so no polynomial rule lies in the interior of T_N for large N; this explains the "degree d works only up to N = d+2" pattern above. ∎ (Exact checks, item 5: β = 1, γ = 0 and β = 0, γ = x fail with the predicted signs for N = 4–14; the Krawtchouk direction β = x, γ = −x has L_even = L_odd = 0.)

Admissible directions already known satisfy both equalities: the Krawtchouk direction, palindromic b = 0 deformations (γ odd about ½, γ(0) = γ(1) = 0), and the geometric q-direction (β = 0, γ = x(x−1)).

**Analytic rules (Nörlund–Rice).** Let U(x) = ∫₀¹ log|x−t| dt and Ω = {x ∈ ℂ : U(x) ≤ −1}. Ω is the Runge "football" of equispaced interpolation: it contains [0,1], has corners at 0 and 1, and crosses Re x = ½ at Im x = ±0.2628. *Lemma.* If f is analytic on an open set containing Ω, then D_N[f] := Σ_{n=0}^{N}(−1)^n C(N,n) f(n/N) = O(√N e^{−ηN}) for some η > 0. *Proof.* Nörlund–Rice: D_N[f] = (−1)^N (N!/N^N)(1/2πi)∮_Γ f(x) dx / Π_{k=0}^{N}(x − k/N), for Γ the boundary of {U < −1+η}. For small η this region lies in the domain of analyticity, by compactness of Ω. On Γ, a Riemann-sum bound for t ↦ log|x−t|, whose derivative is bounded on Γ, gives Σ_k log|x − k/N| ≥ N(−1+η) − C. Stirling gives N!/N^N ≤ e√N e^{−N}. ∎ Hence for β, γ analytic on a neighbourhood of Ω, the corner sum tends to −L_even (even N) or −L_odd (odd N), and admission still forces L_even = L_odd = 0 (nonzero L breaks (P) at infinitely many N). When both vanish the corner derivative is only O(|s_N|√N e^{−ηN}) and need not vanish: β = eˣ − 1 − (e−1)x, γ = 0 gives s_N(1 − e^{1/N})^N. The region is sharp in practice: for f = 1/((x−½)² + y²), |D_N| grows with N for y = 0.20, 0.25 (poles inside Ω) and decays for y = 0.28, 0.35 (outside). Exact 120-digit values are in rigidity_probe.py item 8.

**Deformations depending on N in other ways.** For a single N, T_N has interior, so admissibility of an arbitrary N-dependent family can never be excluded. The corner gives a necessary condition for every admitted family (v_N): σ_N A_N(v_N) ≥ 0 for all large N, with σ_N = (−1)^{⌊N/2⌋+1} and A_N(v) = Σ_{n=0}^{N}(−1)^n C(N,n)F_N(n) the corner sum. σ_N changes sign from N to N+2. Hence:
- (i) Along either parity class the corner sums A_N(v_N) are not eventually strictly positive or eventually strictly negative; an eventual weak sign forces vanishing on the residue class mod 4 where it conflicts with σ_N. (The earlier wording, eventual constant sign implies eventual vanishing, is false for weak signs: the reviewer's directions w_N with δc_n = −2((N−n)/N)C(N−1,n−1) used only for N ≡ 2 mod 4 keep (P) and have A_N > 0 there and 0 elsewhere.)
- (ii) Bulk rules with boundary layers: δb_n = β(n/N) + p_n + q_{N−n} and δc_n = γ(n/N) + p'_n + q'_{N−n}, with β, γ analytic on a neighbourhood of Ω and p, q, p', q' finitely supported and independent of N (q'_0 is an extra change of c_N). Here A_N = (polynomial in N) − L + q'_0 + O(e^{−ηN}), and (i) forces q'_0 = L_even = L_odd, p_k = q_k and p'_k + q'_k = −p_k for k ≥ 1. The layers must be palindromic to first order, and the bulk must satisfy the single equality γ(0) + β(1) + γ(1) = 0 (that is, L_even = L_odd). Separate control of the top coefficient c_N therefore reduces the two bulk equalities to one; it never removes it. Exact check (item 6): β = 1, γ = −½ has L_even = L_odd = ½; its corner slack is −s_N/2 and becomes 0 once c_N is shifted by ½.

**Criteria that avoid r = 1.** The exact value g(N,N;N) = (1−r)^N at K(N,r) follows from Lemma 5.2's model: U_N = y₁⋯y_N and U_N² = Π((1−r)y_i + r). *Proposition.* Fix N and a direction v with ġ := ∂_ε g(N,N;N)(K(N,1) + εv)|₀ < 0, as the Theorem provides for infinitely many N whenever L ≠ 0. Then there are r_* < 1 and C, c > 0 such that K(N,r) + εv lacks (P) for all r ∈ (r_*, 1) and C(1−r)^N ≤ ε ≤ c. *Proof.* G(r,ε) = g(N,N;N)(K(N,r) + εv) is rational and smooth near (1,0), with G(r,0) = (1−r)^N and ∂_εG(r,0) → ġ as r → 1. Taylor's theorem with a uniform second-order bound gives G ≤ (1−r)^N − (3/8)|ġ|ε < 0 in that range. ∎ So a criterion covering r arbitrarily close to 1, but not r = 1, can admit such a direction only with thickness O((1−r)^N). With thickness bounded below uniformly in r, closedness of (P) gives the rule at r = 1 and the Theorem applies. Theorem 5.3's radius η_N(r) is of order (1−r)^N near r = 1, so its exponent N cannot be improved in these directions.
- Fixed r < 1 (evidence, not proved). Fixed-size rules lose (P) at many N for r ∈ (½, 1): exactly, β = 1 with size 1/100 at r = 4/5 for every N = 6–14, and with size 1/1000 at r = 19/20 for every N = 4–14; at r = ½ with size 1/100 it keeps (P) for N = 4–14. - Below r = ½ (corrected 2026-10-21). An earlier note here claimed that fixed-size smooth rules are unobstructed below r = ½. - Small r: shape classes for constant-ratio arrays (smallr_probe.py; exact corner from one column of the product table, O(N²) operations, so N in the hundreds is cheap). Counterexamples at small r were found only at large N, so checks at small N decide nothing there.

At r ≥ ½ most members fail already for N ≤ 14. At r = 1/5 for N ≤ 250 and r = 1/10 for N = 500 every tested member still had a positive corner, so for this class the onset at fixed r lies later than for convex kinks.
  - Outcome of the small-r search (tested families only): the convex class failed at every tested r from 1/10 to ½, the concave class at every tested r, and the log-concave convex class at every tested r from 1/5 to ½ (no failure found at r = 1/10, N = 500). The 80/150-digit results agree but are not exact sign certificates. The deformations that kept the corner positive up to N = 200 were the quadratic profiles x + κx² and smooth changes of c/d; no claim about smooth deformations in general is made.
  - Mechanism (not proved): an interior singularity of the profile, either a jump in the increments or a jump in their ratios, makes the corner oscillate in sign with magnitude above the Krawtchouk value (1−r)^N once N is large. Smooth convex profiles and smooth ratio changes did not show this up to N = 200.

What remains outside the disproof: families whose corner sums oscillate exactly with period 4 in N, including rules with singularities inside Ω tuned to that period (the corner alone cannot exclude these; other structural zeros might); criteria valid only for r ≤ ½; and the equality-type criteria of the paper, which exist.

## The symmetric endpoint: interior directions for every N (2026-10-21)

symmetric_probe.py (exact). Work in measure coordinates: a finite system is its orthogonality measure μ (nodes x₀ > … > x_N, positive weights), with R_n(x₀) = 1 at the top node; product coefficients are invariant under affine changes of x. K(N,1) is the binomial measure 2^{−N}C(N,j) at x_j = 1 − 2j/N.

**Lemma (top mass).** For any finite system, let μ_ε = μ − εδ_{x₀}. If ∫R_xR_yR_z dμ = 0, then
  d/dε|₀ ∫R^ε_xR^ε_yR^ε_z dμ_ε = 2 − [T_x(y,z) + T_y(x,z) + T_z(x,y)],  T_x(y,z) = Σ_{k≥x} g(y,z;k).
*Proof.* Write R^ε_n = R_n + εQ_n + O(ε²), so deg Q_n ≤ n and Q_n(x₀) = 0. First-order orthogonality gives ∫Q_n p dμ = p(x₀) for deg p < n. Hence the R_k-coefficient of Q_n is π_k = 1/∫R_k²dμ for k < n, and Q_n = Σ_{k<n} π_k(R_k − R_n). The derivative is −R_xR_yR_z(x₀) + Σ ∫Q_x R_yR_z dμ (three terms). Each term is Σ_{k<x} π_k∫R_kR_yR_z dμ = Σ_{k<x} g(y,z;k) = 1 − T_x(y,z), since the row sums are 1 and ∫R_xR_yR_z dμ = 0. ∎ Checked exactly at every structural zero of K(N,1) for N ≤ 8.

**Zeros of K(N,1).** The Boolean model of Lemma 5.2 gives g(m,n;k) = Σ_j H(m,n;j) C(j,s) r^{j−s}(1−r)^s for K(N,r), with H(m,n;j) = C(m,j)C(N−m,n−j)/C(N,n) and s = k − m − n + 2j (checked exactly, N = 3, 5, 7). At r = 1 only s = 0 survives. So a triangle coefficient of K(N,1) vanishes exactly when m+n+k is odd (parity zero) or m+n+k > 2N (perimeter zero).

**Theorem (interior directions).** For every N ≥ 2 there is Λ_N < ∞ with the following property. Let the measure be that of K(N, 1 − Λε) with the top mass lowered by ε, where Λ > Λ_N. Then every triangle coefficient is strictly positive for all small ε > 0, so by Lemma 7.5, with Σ the whole triangle, an open set of arrays near it has (P). In particular K(N,1) lies in the closure of the interior of the (P)-region for every N, and the first-order cone T_N has nonempty interior for every N. This replaces the restriction to N ≤ 10.
*Proof.* Both moves are smooth in (r, ε) near (1, 0), and nonzero coefficients stay positive, so only the zeros matter. Rates are first-order changes along each move.
- At a perimeter zero the three tails vanish: g(y,z;k) = 0 for k > 2N − y − z, and x > 2N − y − z. So the top-mass rate is 2π_z > 0. The Krawtchouk rate is ≥ 0, since g ≥ 0 for r ≤ 1 and g = 0 at r = 1.
- At an odd zero with m+n+k ≤ 2N + 1, the Krawtchouk rate is the s = 1 term, H(m,n;j)·j with j = (1+m+n−k)/2. Here j ≥ 1, and j lies in [max(0, m+n−N), min(m,n)] because k − |m−n| is odd and m+n+k ≤ 2N+1. So the rate is strictly positive.
- These two cases cover all zeros. Take Λ_N = max over zeros with negative top-mass rate of (−top rate)/(Krawtchouk rate). ∎

Exact values: Λ_N = 4, 10, 18, 28, 52, 90, 165, 309.4, 554.1 for N = 4,…,12, then 1027.5, 1853.7, 3549, 6750.5 for N = 13,…,16. The worst zeros are low odd triples such as (1,1,1), (2,2,3), (3,3,3). With Λ = 2Λ_N + 1 and ε = 10⁻¹² every triangle coefficient is strictly positive (exact, N = 3–16). These finite values suggest rapid growth, but they establish no asymptotic law and no thickness estimate (point raised in the third review).

**In recurrence coefficients (any finite system).** Lowering the top mass changes the recurrence normalized by R_n(x₀) = 1 at rate (δa_n, δb_n, δc_n) = π_n(a_n, c_n − a_n, −c_n). *Proof.* With Q_n as above, π^ε_n = π_n(1 + ε(2S_n + π_n)) + O(ε²), where S_n = Σ_{k<n} π_k. Differentiate c_n = π_{n−1}∫xR_nR_{n−1}dμ and b_n = π_n∫xR_n²dμ, using xR_m = a_mR_{m+1} + b_mR_m + c_mR_{m−1}, the row sums a_m + b_m + c_m = x₀ and detailed balance π_{n−1}a_{n−1} = π_nc_n. The S-terms cancel: δc_n = −π_{n−1}a_{n−1} = −π_nc_n and δb_n = π_n(b_n + 2c_n − x₀) = π_n(c_n − a_n), and δa_n follows from the row sums. ∎ For K(N,1) this is δc_n = −C(N−1, n−1) and δb_n = −C(N,n)(N−2n)/N (exact for N = 2–12, and on random measures to 10⁻⁴³). This is a binomially concentrated deformation, of width √N around the middle index, not a smooth function of n/N. That is consistent with Theorem 8.4: the interior at the symmetric endpoint is reachable, but not by polynomial or analytic uniform rules.

## Fixed r ∈ (½, 1): the corner derivative at K(N,r) and the threshold ½ (2026-10-21)

fixedr_probe.py (exact derivatives; mpmath quadrature; numpy fit).

**Exact formula.** At K(N,r), R_N(λ_j) = (−r)^j, π_n = C(N,n) r^{−n} and w_j = C(N,j) r^{N−j}/(1+r)^N. The Boolean model gives Σ_j w_j R_n(λ_j) s^j = (r+s)^{N−n} r^n (1−s)^n/(1+r)^N. Repeat Lemma 8.2's argument with Π replaced by R_N(J), whose eigenvalues are (−r)^j, and use (z^i − z^j)/(i − j) = L∫₀¹ z^{θi+(1−θ)j} dθ with z = −r, L = ln r + iπ. Since R_{N−1}(λ_j) − R_N(λ_j) = (−r)^{j−1} j(1+r)/N, the first-order change of g(N,N;N) along the terminal coordinate (δc_N = 1, δb_N = −1) is
  ġ_N(r) = N(−r)/(1+r)^{2N} ∫_γ [h₁(w)^N/(w(w−r²)) + r h₂(w)^N/(w(w+r³))] dw,
  h₁(w) = (1+rw)(1−r²/w),  h₂(w) = (1−w)(1+r³/w),
where γ runs from w = 1 to w = −r through the upper half-plane (substitute w = e^{θL}). This matches the exact derivative to relative error 10⁻¹³ for N = 2–12 and r ∈ {½, 3/5, 4/5, 19/20, 1}. At r = 1 it reduces to Lemma 8.2's terminal value s_N.

**Asymptotics (formal steepest descent; not proved).** The fifth review accepts the saddle moduli and the algebra Q(r) − (1−r) = r(2r−1)/(1+r), but not a proved asymptotic: oscillatory cancellation and the endpoint contributions (factor 1 − r) would have to be controlled. The paper states this only as heuristic evidence.
- h₁ has zeros at r² and −1/r and saddles at w = ±i√r, with h₁(i√r) = (1 + i r^{3/2})².
- h₂ has zeros at 1 and −r³ and saddles at w = ±i r^{3/2}, with h₂(i r^{3/2}) = (1 − i r^{3/2})².
- Both saddle moduli are 1 + r³. The endpoints have |h| = (1−r)(1+r)², which is below 1 + r³ exactly when r > ½, because (1−r)(1+r)² − (1 + r³) = r(1+r)(1 − 2r).
- On [r², 1] and [−1/r, −r], respectively [−r, −r³], h is real and monotone between 0 and the endpoint value. So for r > ½ the two endpoints lie in different valleys of |h_k| below the saddle level, and the path must cross the upper saddle.
- The two saddle values are complex conjugates. Hence
  ġ_N(r) = √N ρ(r)^N (2|c| cos(2Nφ + ψ) + o(1)),  ρ(r) = (1 − r + r²)/(1 + r),  φ = arctan r^{3/2},
  for some c ≠ 0. A least-squares fit over N = 30–60 has relative residual 0.2–0.3% at r = 3/5, 4/5, 19/20, with |c| ≈ 1.9–2.0.
- Since 0 < 2φ ≤ π/2, cos(2Nφ + ψ) ≤ −½ for infinitely many N.

**Threshold.** g(N,N;N) = (1−r)^N, and ρ(r) > 1 − r ⇔ r > ½ (equality at ½). For r ∈ (½, 1) the corner's first-order sensitivity exceeds its value by a factor of order √N(ρ/(1−r))^N, with negative sign infinitely often. The first-order zero crossing along the terminal direction therefore lies at ε* = (1−r)^N/|ġ_N|, exponentially small in N. This explains the earlier numerics exactly: bounded ratio at r = ½, growth like (ρ/(1−r))^N above it.

**Genuine (not only first-order) failure.** The exact corner at ε_N = 3ε*, along the sign of the terminal direction that makes the first-order change negative, is −2.00·(1−r)^N for r = 4/5 (all N = 16–40) and r = 19/20 (all N = 8–40). These are exact rational counterexamples at sizes down to 1.1·10⁻¹⁵ (r = 4/5, N = 40) and 4·10⁻⁴¹ (r = 19/20, N = 40); second-order terms are negligible there. At r = 3/5, where ρ/(1−r) = 1.19, second order still interferes at these sizes (signs mixed up to N = 40).
- Open: a second-order bound (for example |G″| ≪ ρ^N/ε* on [0, 3ε*]) that would make the exponential thinness a theorem for every r ∈ (½, 1).

Every sign set contains 0, so a witness whose higher differences vanish lies in every class its lower-order signs allow. The decisive witnesses are therefore polynomial ones: a quadratic profile (increments 1 + t·i/N) and a linear ratio (ρ_n = r + κn/N).
- Killed (exact, full tables or confirmed corners):
  - S_1 ∋ negative: concave quadratic (increments 1 + t(N−i)/N), N = 3, every r from 1/5 to 1.
  - S_1 = {0}, S_2 ∋ negative: linear profile with linearly falling ratio, r ≥ 2/3 (N = 3–9; corners to N = 320 confirmed at two precisions); no failure at r ≤ ½ up to N = 320.
  - S_1 ∋ positive, S_3 ∋ positive: the segment arrays (increments 1 + t q^{i−N}, all differences ≥ 0), r ≥ 2/7.
  - S_1 ∋ positive, S_3 ∋ negative: increments rising linearly to a plateau, r ≥ 2/3 (N = 4–6).
  - S_1 = {0}, S_2 ∋ positive, S_4 ∋ positive: ratio constant then ramp (the "rising" witness).
  - S_1 = {0}, S_2 ∋ positive, S_4 ∋ negative: ratio rising then flat, r ≥ 1/5 (N = 4–6).
- Survivors: the classes with S_3 = {0} (or S_1 = {0}), S_4 = {0}, S_1 ∈ {[0,∞), {0}}, S_2 ∈ {[0,∞), {0}}. Their members are exactly the two-parameter family
  QL(t, κ): increments 1 + t·i/N (t ≥ 0), ratio ρ_n = r + κn/N (κ ≥ 0),
  with Q = (κ = 0), L = (t = 0), K(N,r) = (t = κ = 0). No member has failed:

- Not classical, apparently. For N = 4, r = ⅓ the characteristic polynomials of L (κ = 1/6), Q (t = 1) and QL have irreducible cubic or quartic factors, whereas Krawtchouk and the classical families have rational nodes for rational parameters.
- Consequence. Within sign conditions on Δ²d, Δ³d, Δρ, Δ²ρ (with monotone a, b, c), every inequality-only class is refuted at large enough ρ_max. The only classes not refuted are equality-type classes whose members form QL, and QL appears to have (P).

## Toward a proof of QL; a candidate inequality criterion (2026-10-22)

Scratch: runs/ql_proof/; tracked ql_symbolic.py.
- *QL proved for N ≤ 6 (exact, symbolic).* With the slack s = (1−r)/2 − κ ≥ 0, each linearization coefficient of QL(t, κ) is a rational function of (κ, s, t). After homogenizing numerator and denominator on the simplex r + 2κ + 2s = 1, both are polynomials in (r, κ, s, t) with nonnegative coefficients. Checked for Q, L, QL at N = 3, 4, 5, 6: 23, 42, 69, 106 nonzero coefficients per family and size, none failing. This proves (P) for QL at these N for all 0 < r < 1, t ≥ 0, 0 ≤ κ ≤ (1−r)/2. Manifest positivity of this kind is the usual trace of a combinatorial model.
- *Q in Newton form.* d_n ∝ n + τC(n+1,2) = (1+τ)(n + σC(n,2)) with τ = t/N, σ = τ/(1+τ). So Q is the profile n + σC(n,2), a "truncated q-number" ([n]_q = Σ_k C(n,k)(q−1)^{k−1}). Q keeps (P) for every σ ≥ 0, not only σ < 1: exact full tables for σ = 1, 2, 5, 20, 100, N ≤ 14, r = ⅕, ½, ⅘, 19/20. (σ ≥ 1 corresponds to t ≤ −N with the increments renormalized.)
- *Candidate criterion (constant ratio + log-concave Newton profile).* Write σ_k = Δ^k d(0), so d_n = Σ_k C(n,k)σ_k. The candidate: b_i/c_i constant, and (σ_1, …, σ_N) nonnegative and log-concave without internal zeros (σ_k² ≥ σ_{k−1}σ_{k+1}).
  - Contains: Krawtchouk (σ = (1,0,…)), every geometric profile (σ_k = (q−1)^{k−1}), Q (σ = (1,σ,0,…)), truncated geometric profiles, and much more.
  - Excludes every known failing family: one-kink, concave, log-concave-increment and log-convex counterexamples (Newton coefficients of both signs); the segment arrays 1 + t q^{i−N} (σ_2² < σ_1σ_3); the absolutely monotone end kinks (internal zeros).
  - Tests, all passed:
    - exact full tables for 750 random log-concave σ, N = 3–12, r = ⅕, ½, ⅘;
    - fixed-point full tables for 544 adversarial members (truncated geometric with q − 1 up to 3 and cut-offs K = 2, 3, N/4, N/2; two-level ratio sequences; smoothly decaying ratios; random nonincreasing ratios), N = 16, 20, 24, 30, r = 0.1, 0.2, 0.5, 0.8, negatives recomputed at +800 bits;
    - fixed-point corners for 680 such members at N = 50, 100, 200, 400 and r = 0.1, 0.2, ⅓, ½, 0.8 (smallest ratio to (1−r)^N: 14.9).
    The full-table code finds the known counterexamples, for instance the segment value −7.851·10⁻⁶.
  - It is an inequality criterion except for the constant ratio (an equality). The rising linear ratio (L) suggests the ratio condition can also be relaxed; not yet formulated.
- *Proof idea.* In the geometric tower algebra the raising coefficient of E_1E_k is [k+1]_q = Σ_u C(k+1,u)σ_u: nonempty subsets U of a (k+1)-set weighted by σ_{|U|}. A tower whose square relations carry higher-order terms z_j z_U (U above j) with weights λ_{|U|} ≥ 0 would give D(k+1) = Σ_u C(k+1,u)σ_u after full reduction. The open question is whether log-concavity of σ is exactly what makes the required λ nonnegative, and whether the lowering coefficients (the ν_j) can be chosen so that E_1E_k closes on the E's.

## Tower-algebra route for the log-concave criterion: negative (2026-10-22)

Scratch: runs/ql_proof/tower*.py.
- *Target.* In the normalization of Theorem 2.1, the criterion needs a commutative algebra with a positive squarefree basis z_S in which E_1E_k = D(k+1)E_{k+1} + (p−1)D(k)E_k + p(D(N) − D(k−1))E_{k−1}, D(n) = Σ_u C(n,u)σ_u. The geometric σ_u = (q−1)^{u−1} gives Theorem 2.1's coefficients exactly. Gauge-invariant form: β_k = τ(1−r)D(k)/D(N) and α_{k−1}γ_k = τ² r D(k)(D(N) − D(k−1))/D(N)².
- *Constraint.* Square relations cannot contain z_j z_U with |U| ≥ 2: when U misses T these produce E_{k+2}, and nonnegative coefficients cannot cancel. Higher Newton coefficients must come from chains of degree-one raisings.
- *Ansatz tested (N = 3).* z_j² = Σ_{l>j}(λ_{jl} z_j z_l + η_{jl} z_l) + Σ_{j<l<m} θ_{jlm} z_l z_m + μ_j z_j + ν_j, all coefficients ≥ 0, position-dependent, gauge-invariant targets.
  - Solvable (residual 10⁻²⁶ to 10⁻³⁰) exactly for geometric σ: (1,1,1) gives λ ≡ 1, ν = 8,4,2; (1,½,¼) gives λ ≡ ½, ν = 4.5,3,2. These are Theorem 2.1's algebra.
  - Not solvable for Q, σ = (1,½,0), nor for the log-concave σ = (1,½,⅛): best least-squares residual 6.8·10⁻³ and 1.6·10⁻³ over 300 random starts. Exact symbolic solving with fixed gauge also has no solution.
  So chains in an ordered tower force σ_3 = σ_2² (geometric); Q's positivity needs a different mechanism.
- *Structural picture.* Mixtures of geometric profiles have σ_k = E[X^{k−1}], a moment sequence, hence log-convex. The failing segment arrays K(N,r) → G(N,q,r) are exactly the two-point mixtures (masses at X = 0 and X = q − 1). Geometric profiles (log-linear) are the common boundary. Empirically: log-convex fails (segment), the boundary is Theorem 2.1, log-concave passes (all tests so far). A proof will likely need a model in which the chain weight depends on chain length (σ_{u+1}/σ_u = ρ_u nonincreasing), not on position.

## Log-concave Newton criterion: exact certificate for small N (2026-10-22)

lc_certificate.py (tracked); scratch runs/ql_proof/lc_poly*.py.
- *Parametrization.* σ_1 = 1, σ_{k+1} = σ_k ρ_k, ρ_k = x_k + x_{k+1} + … + x_{N−1} with x_i ≥ 0: this gives every nonnegative log-concave sequence with σ_1 = 1. With r = R/(R+W), R, W > 0, the whole criterion region (constant ratio, log-concave Newton profile) is the nonnegative orthant in (R, W, x).
- *Fraction-free recurrence.* Multiplying each step of the linearization recurrence by (R+W)(D_N − D_m) keeps every entry polynomial: g(m,n;k) = P_{mnk}/Q_m with Q_m = Π_{m′<m}(R+W)(D_N − D_{m′}). Q_m has positive coefficients because D_N − D_{m′} = Σ_k (C(N,k) − C(m′,k))σ_k. If every P_{mnk} has nonnegative coefficients, (P) holds for every member at that N.
- *Result.* All numerators have nonnegative coefficients for N = 2, 3, 4, 5 (11, 23, 42, 69 nonzero coefficients). So the criterion is proved for N ≤ 5, for all 0 < r < 1 and all log-concave σ. At random rational points the certificate values equal the exact linearization coefficients (N = 3, 4).

These are exactly the corner and deep triples where failures occur at larger N, so the test discriminates.

In the raw quotient variables, the negative terms sit only in the top two Bernstein coefficients, and only on deep triples: N = 4, g(4,4;4), R-degrees 3–4; N = 5, g(4,5;5), g(5,5;5) at R-degrees 3–4 and g(5,5;4) at 4–5. Here β_4 is the r = 1 corner (b ≡ 0, c = d), and in Newton variables −Y has 17 terms, one negative (−ρ1ρ2ρ3). At N = 5 (generic profile): β_1/β_0 = 1 − 1/(5a_4); β_3 = β_4 = a_1²a_2³a_3²·Z/5 with Z = 5a_1a_2a_3a_4 − 2a_1a_2a_3 + d_4(a_3 − a_4)(a_1 + a_2 − a_4); β_2 = a_1²a_2³a_3²·(Z + a_1a_2a_3(5a_4 − 1))/10; β_5 = 0 (parity at r = 1). In the same form, at N = 4, −Y = 2a_1a_2a_3 − a_1a_2 + d_3(a_2 − a_3) and the β_2 factor is −Y + a_1a_2(4a_3 − 1). Krawtchouk has corner exactly (1−r)^N, so every β_j with j ≥ 1 vanishes there: these coefficients measure the excess over Krawtchouk. At N = 4, 5 the corner is nonnegative for all r if N·a_{N−1} ≥ 1 (true for convex profiles) and one top quantity (−Y, resp. Z) is ≥ 0. - *Lemma (all N): the first Bernstein coefficient of the corner.* For a constant-ratio array with any profile 0 = d_0 < … < d_N = 1, d/dr g(N,N;N) at r = 0 equals −1/a_{N−1}; equivalently β_1/β_0 = 1 − 1/(N·a_{N−1}). Proof: T(r) = R_N(J(r)) is the unique matrix commuting with J(r) whose row 0 is e_N^T, and its row N is the corner row. At r = 0, J_0 is upper bidiagonal with diagonal d_0, …, d_N and R_N(x) = Π_{t<N}(x − d_t)/a_t, so R_N(J_0) = 1·e_N^T (the spectral projection on the eigenvalue d_N = 1, with right eigenvector 1 and left eigenvector e_N). Differentiating TJ = JT with J′ = B = D(S⁻ − I) gives T′J_0 − J_0T′ = BT_0 − T_0B = −1·(e_{N−1} − e_N)^T, because B1 = 0 and e_N^TB = e_{N−1}^T − e_N^T. Row N of this, using e_N^TJ_0 = e_N^T, says x^T(J_0 − I) = −(e_{N−1} − e_N)^T for x^T = e_N^TT′, that is x_{k−1}a_{k−1} − x_ka_k = −δ_{k,N−1} + δ_{k,N}. With a_0 = 1 this forces x_k = 0 for k ≤ N − 2 and x_{N−1} = 1/a_{N−1}. Rows of T sum to R_N(1) = 1 for every r, so Σx_k = 0 and x_N = −1/a_{N−1}. Convexity gives a_{N−1} = d_N − d_{N−1} ≥ 1/N, so β_1 ≥ 0 for every convex profile, with equality exactly when the last increment is 1/N (as for Krawtchouk).
- Naming: the candidate constrains the Newton coefficients Δ^k d(0) of the profile. It is not the refuted "log-concave increments" class of Section 9; those counterexamples have Newton coefficients of both signs and are excluded.

## Constant-ratio criterion: Bernstein positivity in r (2026-10-22)

Scratch: runs/ql_proof/corner_bern*.py, full_bern.py, full_bern_big.py.
- For a fixed profile, every g(m,n;k) of the constant-ratio array (a = 1 − d, b = (1−r)d, c = rd) is a polynomial in r of degree ≤ m. The N ≤ 6 certificate (lc_certificate.py) proves more than (P): the numerators have nonnegative coefficients in (R, W), so every g(m,n;k) has nonnegative Bernstein coefficients of degree m in r. Equivalently g(m,n;k) = E[w_{mnk}(J)] with J ~ Binomial(m, r) and weights w ≥ 0 that depend only on the profile (binomial thinning). For Krawtchouk, the corner (1−r)^N is the case w = δ_0.
- *Conjecture (B) (a route, not the target).* For every profile with nonnegative log-concave Newton coefficients and every N, all g(m,n;k) have nonnegative degree-m Bernstein coefficients in r. (B) implies the constant-ratio criterion for all r ∈ [0, 1]. The target stays property (P). (B) is stronger, because a polynomial can be nonnegative on [0, 1] with some negative Bernstein coefficients, so a failure of (B) would not refute the criterion. (B) is worth pursuing only because it is the form an induction can carry, and the N ≤ 6 certificate already has it.
- *Evidence (exact rational arithmetic, all triples).* Full tables at N = 6, 8, 10 (13 boundary profiles each: geometric, truncated geometric with K = 2, 3, N/2, two-level; x ∈ {1/10, 1, 9}) and at N = 16, 20, 24, 30 (15 profiles each, including random log-concave quotients): no negative Bernstein coefficient on any triple. Corners only: 96 boundary profiles at N = 10–40 and random log-concave profiles at N = 8–30, none negative.
- *Control.* On the segment arrays d = (1−λ)n/N + λ(10^n − 1)/(10^N − 1) (log-convex Newton coefficients), λ = 1/20 gives 7, 18, 37 triples with negative Bernstein coefficients at N = 6, 8, 10, all of them deep. Non-deep triples have nonnegative Bernstein coefficients even there, which suggests a Bernstein form of Corollary 7.11. At larger N the corner of these arrays has negative middle coefficients (N = 19, λ = 1/20: j = 5–7 and 12–16), while β_1 and the top coefficients stay nonnegative. So the small-N picture (only the top two coefficients need log-concavity) does not persist, and the hypothesis that every corner coefficient is a nonnegative combination of N·a_{N−1} − 1 and one top quantity is false for general convex profiles by N = 19.
- *Route.* An all-N proof of (B) needs either a binomial-thinning construction (each of m steps independently a "down" with probability r) with nonnegative weights for log-concave Newton profiles, or a coefficientwise version, in (R, W), of the maximum-principle argument of Theorem 7.10 together with a deep-triple argument. The homogeneous recurrence is a_mG_{m+1}(i) = W(d_i − d_m)G_m(i) + Rd_iG_m(i−1) + (R+W)a_iG_m(i+1) − R(R+W)d_mG_{m−1}(i), with G_m = (R+W)^m g_m; its only negative term is the last.

## Non-deep triples in Bernstein form: proof for all N (2026-10-22)

runs/ql_proof/bern_nondeep.py (exact check of the identity and of the term classification: 2540 identities, N = 3–8, convex random profiles and random r, 0 failures, deep pairs included).

*Proposition.* Constant ratio (a = 1 − d, b = (1−r)d, c = rd) with 0 = d_0 < d_1 < … < d_N = 1 and d_i + d_j ≤ 1 whenever i + j ≤ N − 2 (implied by convexity). If n ≥ m and n + m ≤ N, then for every k, g(n,m;k) is a polynomial in r with nonnegative Bernstein coefficients of degree m. Every non-deep triple has g(n,m;k) equal to a polynomial with nonnegative Bernstein coefficients in some degree ≤ N.

*Proof.*
1. *Transposed normalization.* q_n = κ_nR_n with κ_n = Π_{t<n} a_t/c_{t+1} = r^{−n}A_n, where A_n = Π_{t<n}(1 − d_t)/d_{t+1} does not depend on r. On the support, x q_n = c_{n+1}q_{n+1} + b_nq_n + a_{n−1}q_{n−1} for 0 ≤ n ≤ N (c_{N+1} := 0; at n = N this is the terminal relation). Fix k. Let u(i,j) be the coefficient of q_k in q_iq_j, and ĝ(i,j) = u(i,j) r^{i+j−k} = g(i,j;k)A_iA_j/A_k. Then ĝ(i,0) = δ_{ik}. Computing x q_i q_j in two ways gives Hu = 0 on {0,…,N}², with H = L_1 − L_2 and Lu(i) = c_{i+1}u(i+1) + b_iu(i) + a_{i−1}u(i−1).
2. *Cone and weights.* Let i_0 = n − m + 1 and S = {(i,j): 0 ≤ j < m, |i − n| < m − j, i ≡ n + m − j − 1 (mod 2), i ≤ N}, with v(i,j) = r^{(i+j−i_0)/2} on S (an integer power) and 0 elsewhere. Then 0 = ⟨Hu, v⟩ = ⟨u, H*v⟩, where H*v(i,j) = c_iv(i−1,j) + a_iv(i+1,j) + (b_i − b_j)v(i,j) − c_jv(i,j−1) − a_jv(i,j+1).
3. *Interior terms vanish.* At a point off S with all four neighbours in S, H*v = r^e[rd_i + r(1 − d_i) − rd_j − r(1 − d_j)] = 0. This is the point of the weight √r per step, and it is what makes α + γ constant in Corollary 7.11. At i = N nothing new appears, because a_N = 0.
4. *Remaining terms.*
   - On S: (1 − r)(d_i − d_j)v(i,j).
   - Right edge i + j = n + m (i ≤ N): r(d_i − d_j)v(i−1,j).
   - Left edge i − j = n − m: r(1 − d_i − d_j)v(i,j−1) for j ≥ 1, and a_{n−m} at (n−m, 0).
   - At (n,m): −r^m d_m.
5. *The identity.* Multiplying by r^{n+m−k}:
   d_m ĝ(n,m) = Σ_{(i,j)∈S} (1−r) r^{(n+m−1−i−j)/2}(d_i − d_j) ĝ(i,j) + Σ_{j<m} (d_{n+m−j} − d_j) ĝ(n+m−j, j) + Σ_{1≤j<m} r^{m−j}(1 − d_{n−m+j} − d_j) ĝ(n−m+j, j) + r^m(1 − d_{n−m}) ĝ(n−m, 0).
   Every point used has j < m, i ≥ j and i + j ≤ n + m.
6. *Induction on m.* Assume each ĝ(i,j) has nonnegative Bernstein coefficients of degree j.
   - Each term is a nonnegative profile constant times r^p(1−r)^q ĝ(i,j) with p + q + j ≤ m. On S, i ≥ n − m + j + 1 gives (n+m−1−i−j)/2 ≤ m − j − 1.
   - The constants are nonnegative: d_i ≥ d_j for i ≥ j; on the left edge i + j = n − m + 2j ≤ n + m − 2 ≤ N − 2, so 1 − d_i − d_j ≥ 0.
   - Products of Bernstein-nonnegative polynomials are Bernstein-nonnegative in the sum of the degrees (multiply the homogenized forms in (R, W)), and degree elevation keeps nonnegativity.
   - So ĝ(n,m) has nonnegative Bernstein coefficients of degree m.
7. *Other triples.* g(n,m;k)h_k is symmetric, with h_k = ∫R_k² dμ = r^k/A_k. So ĝ(n,m;k) r^k A_k is symmetric in all three indices, and the other two orderings of a triple are r^{±s} times positive constants times ĝ(n,m;k). If P = r^sQ is Bernstein-nonnegative in degree p, then Q is Bernstein-nonnegative in degree p − s (divide the homogenized form by R^s). ∎

This proves (B) on all non-deep triples for every convex profile, log-concave or not. It is consistent with the controls: the segment arrays have negative Bernstein coefficients only on deep triples.

*Deep pairs: where the identity breaks.* The identity of step 5 holds verbatim for deep pairs too (checked). The truncation i ≤ N only removes right-edge terms, which are nonnegative. The only negative terms are on the left edge: r^{m−j}(d_i + d_j − 1)ĝ(i,j) with i = n − m + j and d_i + d_j > 1 (so i + j ≥ N − 1). For Krawtchouk the coefficient is (i + j − N)/N. So positivity on deep triples is exactly the question of whether the S-terms and the right-edge terms outweigh this left-edge deficit. Log-concavity must enter there, since the log-convex segment arrays fail.

*Deep pairs: size of the deficit (runs/ql_proof/deep_edge.py, deep_cols.py; N = 8, r ∈ {1, 1/2, 1/10}).* The positive terms barely beat the left-edge deficit. At r = 1 the smallest positive/deficit ratios are 1.0000 for Krawtchouk (where g = 0), 1.002 for geometric x = 1/10, 1.08–1.38 for log-concave profiles with larger quotients, and 0.9992 for the failing convex profile (increments 2, 14, 16, 26, 30, 30, 32, 33, at (8,8;8)). The minimum is always at the corner (8,8;8), or at (8,8;0) for small r. Column by column there is no domination: in most deficit cases some column j has a negative sum (at r = 1, 0 of 40 Krawtchouk cases have all column sums ≥ 0). So the identity at deep pairs carries no local slack. A proof through it must use global cancellation, which is the earlier finding that light-cone certificates on deep triples are as hard as (P). No stronger local induction hypothesis (column or edge monotonicity) is suggested by the data.

*Heavy top: an all-triple inequality criterion (proved; runs/ql_proof/heavy_top.py).* The only negative terms of the identity, at every pair, are the left-edge constants 1 − d_i − d_j with 1 ≤ j ≤ i ≤ N − 1. Hence:
**Proposition.** If the constant-ratio profile is increasing and d_{N−1} ≤ 1/2 (last increment at least 1/2), then every g(m,n;k) has nonnegative Bernstein coefficients in r, so (P) holds for all r ∈ [0, 1]. Convexity is not needed: the S-terms and right-edge terms only use d_i ≥ d_j for i > j, and the interior cancellation is exact for every profile.
Exact check: 220 random increasing, non-convex profiles with d_{N−1} ≤ 1/2, N = 3–12, have no (P) failure at r ∈ {1, 1/2, 1/7} and no negative Bernstein coefficient. The same shapes with d_{N−1} ∈ [0.6, 0.99] fail in 173 of 220 cases.
The general form is Theorem 7.10 with (i) and (ii) extended up to N (γ_N = 0, so (ii) at N reads α_N ≥ α_{N−1} + γ_{N−1}) and (iii) γ_i ≥ α_j for all 0 ≤ j ≤ i ≤ N − 1. Its proof is the paper's, with the terminal relation used at row N; the restriction n + m ≤ N in the paper is only needed for (iii). This is an inequality criterion "valid including the terminal indices" in the sense of the paper's Section 8 remark, so Theorem 7.8 transfers it to symmetric systems. It contains the geometric arrays with q ≥ 2, but not Krawtchouk (N ≥ 3), whose left-edge constants are (N − i − j)/N. So the open deep-triple problem is exactly the regime where γ_i < α_j at i + j ≥ N − 1, that is, profiles with d_{N−1} > 1/2 (Newton quotients small, near Krawtchouk).

*The endpoint r = 1 (b ≡ 0, c = d; runs/ql_proof/r1_test.py).* This is the top Bernstein coefficient. Exact full tables for N = 4–12: random convex profiles fail in 3 of 30 cases at N = 8 (e.g. g(6,8;8) ≈ −6.8·10⁻⁷), while random log-concave and random log-convex Newton profiles pass (130 each). So the r = 1 endpoint needs more than convexity, but not log-concavity specifically. The segment failures (log-convex, small r) are a different mechanism: their bad Bernstein coefficients are in the middle.
